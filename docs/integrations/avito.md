# Авито

Каркас интеграции: дилер сохраняет ключи приложения и проверяет, что поля заполнены. Автопост лота в объявления Авито появится после партнёрского доступа площадки.

## Что умеет CRM сейчас

- Карточка канала **Авито** в кабинете дилера.
- Сохранение `client_id`, `client_secret` / user token, опционально `profile_id`.
- **Проверить связь** — валидация полей без фейкового успешного HTTP к API Авито.
- Автопост в outbox помечается `needs_partner`, пока нет партнёрских ключей.

## Как получить ключи

1. Зарегистрируйте кабинет разработчика на [developers.avito.ru](https://developers.avito.ru/) (названия разделов могут меняться).
2. Создайте приложение и дождитесь модерации — без неё боевые методы часто недоступны.
3. Скопируйте `client_id` и `client_secret`.
4. При необходимости укажите user token и `profile_id` кабинета продавца.
5. В CRM: **Каналы → Авито → Сохранить → Проверить связь**.

## Ограничения API

- Модерация кабинета разработчика и лимиты на создание объявлений.
- Категории «Авто» требуют отдельных полей (VIN, пробег, комплектация) — маппинг появится вместе с publish.
- Публикация без партнёрского договора часто закрыта.

## Переменные площадки

После получения партнёрского доступа добавьте в `.env`:

```
AVITO_CLIENT_ID=...
AVITO_CLIENT_SECRET=...
```

Пока переменных нет, в карточке канала видна подсказка про `needs_partner`; воркер не падает.

## Что появится после партнёрского доступа

- Реальный `Test` через OAuth/token Авито.
- Автопост активного лота (текст, фото, ссылка на карточку CRM) в объявление или черновик.
