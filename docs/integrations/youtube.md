# YouTube

В этой версии подключаем канал и проверяем связь. Автозагрузка ролика появится, когда в лоте будет видео: исходника для `videos.insert` сейчас нет.

Клиент Google создаёт **площадка один раз**. Дилер жмёт «Подключить YouTube».

## Что создать

Google-аккаунт с YouTube-каналом.

## Куда кликать

1. На странице **Каналы** нажмите **Подключить YouTube**.
2. Войдите в Google и разрешите доступ (чтение канала и загрузка видео на будущее).
3. Согласие должно быть offline: CRM сохраняет refresh token.
4. После возврата нажмите **Проверить связь** — должен показаться заголовок канала.

Кнопка серая: в `.env` площадки нет `GOOGLE_OAUTH_CLIENT_ID` / `GOOGLE_OAUTH_CLIENT_SECRET`.

## Как проверить

Проверка вызывает YouTube Data API `channels.list?mine=true`.

В карточке канала явно написано: «Ролик можно будет слать, когда в лоте появится видео». Очередь автопоста для YouTube помечается как пропущенная, остальные сети это не роняет.

## Типичные ошибки

- У Google-аккаунта нет YouTube-канала.
- Отказ в consent / нет `prompt=consent` — не придёт refresh token, через час придётся подключать снова.
- Просроченный доступ — статус «Обновите ключ», дилер жмёт «Подключить» ещё раз. Площадка не участвует.
