# Дром

Каркас интеграции: дилер сохраняет user token и `profile_id`. Автопост лота на Дром — после партнёрского ключа площадки.

## Что умеет CRM сейчас

- Карточка канала **Дром** в кабинете дилера.
- Сохранение user token / api key и `profile_id`.
- **Проверить связь** — проверка, что обязательные поля заполнены (без фейкового успешного поста).
- Автопост в outbox помечается `needs_partner`, пока нет `DROM_API_KEY`.

## Как получить ключи

1. Оформите доступ к API Дрома (партнёрский кабинет / договор — условия на стороне Дрома).
2. Получите user token или api key и идентификатор профиля/кабинета.
3. В CRM: **Каналы → Дром → Сохранить → Проверить связь**.

## Ограничения API

- Часто нужен whitelist IP и отдельная модерация кабинета.
- Формат объявлений (комплектация, регион, фото) отличается от внутреннего лота CRM — потребуется маппинг.
- Без партнёрского ключа площадки боевой publish недоступен.

## Переменные площадки

```
DROM_API_KEY=...
```

Пока ключа нет, publish пропускается с пометкой `needs_partner`, остальные каналы не затрагиваются.

## Что появится после партнёрского доступа

- Реальный `Test` к API Дрома.
- Автопост лота после модерации (цена, фото, ссылка на карточку).
