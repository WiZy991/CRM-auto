# ВКонтакте

Пост на стену сообщества: текст лота и ссылка. Токен должен быть **токеном сообщества**, не пользователя.

## Что создать

Сообщество ВКонтакте и ключ доступа этого сообщества.

## Куда кликать

1. Откройте сообщество ВКонтакте → **Управление** → **Работа с API** → **Создать ключ**.
2. Права ключа: стена (`wall`) как минимум.
3. Скопируйте ключ в поле «Токен сообщества» на странице **Каналы**.
4. `owner_id` — идентификатор группы **с минусом**. Если адрес `vk.com/club123456`, owner_id = `-123456`.
5. Числовой id также виден в **Управление → Настройки**.
6. Нажмите **Сохранить**, затем **Проверить связь**.

Позже площадка может включить OAuth сообщества. Пока достаточно вставки ключа.

## Как проверить

Проверка вызывает `groups.getById`. Если группа находится, статус зелёный.

## Типичные ошибки

- Токен пользователя вместо сообщества — `wall.post` с `from_group` будет отклонён.
- `owner_id` без минуса — пост уйдёт не на стену группы.
- Ключ без права «стена».
