# WeChat (бизнес-аккаунт)

Интеграция с **офиполнительным аккаунтом WeChat для бизнеса** (Official Account / Service Account): дилер сохраняет AppID и AppSecret своего кабинета, CRM проверяет связь через `access_token` и может положить лот в **черновики**.

Личный WeChat и лента Moments **не** поддерживаются публичным API для автопостинга объявлений. Нужен кабинет [mp.weixin.qq.com](https://mp.weixin.qq.com/).

## Что умеет CRM сейчас

| Действие | Статус |
|----------|--------|
| Сохранение AppID + AppSecret | да |
| «Проверить связь» (`cgi-bin/token`) | да, реальный вызов |
| Автопост лота | черновик в кабинете WeChat |
| Автопубликация в ленту | нет — лимиты площадки, дилер публикует из кабинета |

## Как получить ключи

1. Зарегистрируйте или войдите на [mp.weixin.qq.com](https://mp.weixin.qq.com/). Для API удобнее **сервисный** аккаунт (Service Account), подойдёт и подписочный (Subscription Account).
2. Пройдите верификацию организации, если планируете публикацию — без неё часть методов закрыта.
3. Раздел **«Настройки и разработка» → «Базовая конфигурация»**:
   - скопируйте **AppID**;
   - сгенерируйте **AppSecret** (показывается один раз).
4. На той же странице добавьте **белый список IP**: исходящий IP сервера CRM. Без него WeChat отвечает ошибкой `40164`.
5. В CRM: **Каналы → WeChat** → AppID + AppSecret → **Сохранить** → **Проверить связь**.

Тестовый аккаунт для разработки: [песочница WeChat MP](https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo) (ограничения по сравнению с боевым сервисным аккаунтом).

## Как устроен API (кратко)

1. `GET /cgi-bin/token?grant_type=client_credential&appid=&secret=` → `access_token` (~2 часа, лимит ~2000 вызовов/сутки на AppID).
2. Загрузка обложки: `POST /cgi-bin/material/add_material?type=image`.
3. Черновик: `POST /cgi-bin/draft/add` с заголовком, `thumb_media_id` и HTML-текстом.
4. Публикация вручную в кабинете WeChat или позже через `freepublish/submit` (отдельный этап).

Официальная документация: [developers.weixin.qq.com](https://developers.weixin.qq.com/doc/offiaccount/Getting_Started/Overview.html).

## Ограничения

- Картинки в статье должны быть из медиахранилища WeChat — чужие URL в тексте отфильтруются.
- Заголовок короткий (~32 иероглифа / короткая строка).
- Групповая рассылка и автопубликация: жёсткие квоты (у сервисного аккаунта порядка 4 mass-send в месяц; freepublish — отдельно).
- Сервер CRM должен ходить на `api.weixin.qq.com` (нужен стабильный исходящий IP в whitelist).
- WeChat Work (корпоративный мессенджер для сотрудников) — другой продукт; в этой версии не подключён.

## Поля в CRM

| Поле | Что это |
|------|---------|
| AppID | идентификатор аккаунта (`client_id`) |
| AppSecret | секрет приложения (`client_secret`) |

## Типичные ошибки

| Код / симптом | Что делать |
|---------------|------------|
| `40164` | Добавить IP сервера в whitelist кабинета WeChat |
| `40125` / `40013` | Неверный AppSecret или AppID |
| `40001` / `42001` | Просроченный token — нажать «Проверить связь» снова |
| Нет фото у лота | Черновик не создаётся: нужна обложка |
| Черновик есть, в ленте нет | Откройте черновики в кабинете WeChat и опубликуйте вручную |

## Что появится дальше
