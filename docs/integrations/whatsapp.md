# WhatsApp

WhatsApp — **не лента**. Ключи сохраняем и проверяем. Автопост лота возможен только как сообщение в WhatsApp Channel или указанный чат Cloud API, не как «пост на стену».

## Что создать

WhatsApp Business Account (WABA) в Meta Business Suite и постоянный системный токен.

## Куда кликать

1. Откройте [Meta Business Suite](https://business.facebook.com/) → WhatsApp Manager → нужный WABA.
2. Скопируйте **постоянный** токен системы, не короткий токен из Graph Explorer (он истекает за сутки).
3. `phone_number_id` и `WhatsApp Business Account ID` лежат в настройках номера.
4. Поле «Куда постить»: id канала WhatsApp или номер чата в международном формате без плюса.
5. Пустое поле «Куда постить» — лоты не отправляются, проверка связи всё равно работает.
6. На странице **Каналы** вставьте поля, нажмите **Сохранить**, затем **Проверить связь**.

## Как проверить

Проверка запрашивает номер через Graph API (`GET /{phone_number_id}`). Успех — «Связь есть».

## Типичные ошибки

- Временный токен из Graph Explorer.
- Неверный `phone_number_id` — Graph вернёт 404.
- Сообщение в чат не уходит, если не заполнен получатель: это ожидаемо, не ошибка площадки.
