# RuTube

Ключ по текущей документации RuTube. Партнёрский API нестабилен: ошибка RuTube не роняет остальные каналы и не требует участия площадки.

Автозагрузка ролика в этой версии не включена — только сохранение ключа и проверка, что он живой.

## Что создать

Кабинет автора RuTube и API key / user token, как их описывает актуальная документация RuTube.

## Куда кликать

1. Откройте кабинет автора RuTube и раздел API / интеграции (пункты меню на стороне RuTube меняются).
2. Создайте API key или user token.
3. В CRM, страница **Каналы**, вставьте значение в поле ключа.
4. Нажмите **Сохранить**, затем **Проверить связь**.

## Как проверить

Проверка делает `GET` профиля. Любой осмысленный 2xx — «Связь есть». 401/404 — ключ или маршрут API устарели, обновите ключ по новой доке RuTube.

## Типичные ошибки

- Партнёрский endpoint сменился — это не падение CRM. Обновите ключ, когда RuTube отдаст новый.
- Пустой ключ после копирования из письма с переносом строки.
