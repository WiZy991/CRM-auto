# Telegram

Лот после модерации уходит в ваш канал: марка, модель, год, цена, фото и ссылка на карточку.

## Что создать

Бот в Telegram и канал (или группа), куда бот будет писать.

## Куда кликать

1. Откройте Telegram, найдите `@BotFather` и отправьте `/newbot`.
2. Задайте имя и username бота.
3. Скопируйте HTTP API token — длинную строку. Это поле «Токен бота» в CRM.
4. Создайте канал или возьмите существующий.
5. Добавьте бота **администратором** канала с правом публиковать сообщения.
6. В CRM, страница **Каналы**, укажите `@username` канала или числовой `chat_id`. Для приватного канала chat_id можно узнать, переслав пост боту `@userinfobot`.
7. Нажмите **Сохранить**, затем **Проверить связь**.

## Как проверить

Зелёный статус «Связь есть» значит, что `getMe` и `getChat` прошли: бот жив и видит канал.

## Типичные ошибки

- Бот не админ — Telegram отвечает, что чат не найден.
- Токен обрезан при копировании — пробел в начале или конце.
- Указан username человека вместо канала.
